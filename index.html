NTBase 使い方マニュアル

テニス・ピックルボールの試合動画を観る、大会チケット（PPV）を買う、選手を応援する。NTBase のすべての使い方をまとめました。

視聴者の方 動画視聴・PPV購入・投げ銭（応援）・ランキング 選手の方 クラブ招待の承認・プロフィール・応援の受け取り・出金 団体（クラブ）の方 選手管理・大会作成・動画アップロード・売上と出金

VIEWER GUIDE 01

登録なしでもできること

ホーム・動画一覧（テニス / ピックルボール / 人気 / 最新）・大会一覧・選手プロフィール・ランキング・検索は、ログインなしで自由に閲覧できます。

無料の会員登録が必要な機能：PPV購入、投げ銭（応援）、マイリスト、視聴履歴、購入済みPPV、応援履歴、選手のフォロー、コメント投稿。

よく出てくる用語

用語意味
PPV（ピーピーブイ）大会ごとに購入する視聴チケットのこと（Pay Per View）。購入するとその大会の全試合が視聴できます
P（ポイント）投げ銭に使う単位。1P = 1円です
投げ銭（応援）好きな選手や団体にポイントを送って応援する機能。応援ランキングにも反映されます
マイリスト気になる動画を保存しておく自分専用のリスト
大会（トーナメント）試合動画のまとまり。動画の購入は大会単位で行います

VIEWER GUIDE 02

会員登録・ログイン

  1. ログイン画面から「新規登録」へ。姓・名・メールアドレス・パスワードを入力し、利用規約に同意して登録します。パスワードは大文字・小文字・数字をすべて含めてください。
  2. 届いた認証メールのリンクをクリックして認証を完了します。認証が済むまでログインできません。
  3. メールアドレスとパスワードでログイン。「ログイン情報を記憶する」で次回の入力を省略できます。

パスワードを忘れたときは、ログイン画面の「パスワードをお忘れですか？」から再設定メールを受け取れます。リンクの期限が切れた場合は再送できます。

VIEWER GUIDE 04

動画を観る

  • 無料動画は「無料で視聴する」からそのまま再生できます。
  • 有料動画は「プレビューを見る」「トレーラーを見る」で一部を無料視聴できます。本編は大会のPPV購入後に視聴できます。
  • 動画ページでは、マイリストへの追加、コメントの閲覧・投稿（いいね / 低評価）、関連動画の表示ができます。
  • 観た動画は自動的に視聴履歴へ記録されます。

VIEWER GUIDE 05

PPV（大会チケット）を購入する

有料コンテンツは大会単位の買い切りです。月額サブスクリプションはありません。購入すると、その大会の全試合が視聴可能になります。

  1. マイページの支払い方法画面でクレジットカードを登録します（初回のみ）。セキュリティコード（CVV）は保存されません。
  2. 大会詳細ページ、または有料動画の「動画を購入する」から購入画面へ進みます。
  3. 「確認して支払う（○○円）」で決済。登録済みカードから支払われます。
  4. 購入後は「購入済みPPV」からいつでも視聴できます。同じ大会が二重に課金されることはありません。
ご注意：ご利用いただける支払い方法はクレジットカードのみです（コンビニ払い・銀行振込には対応していません）。日本国外発行のカードはご利用いただけない場合があります。無料（0円）で公開されている大会もあります。

VIEWER GUIDE 06

投げ銭（応援）する

好きな選手や団体にポイント（1P = 1円）で応援を送れます。応援メッセージを添えることもできます（最大100文字）。

応援先プリセット金額金額の範囲
選手100 / 500 / 1,000 / 5,000100P〜50,000P
団体（クラブ）100 / 500 / 1,000 / 3,000 / 5,000 / 10,000100P〜50,000P
  • 表示名は 匿名のファン ログイン名 ニックネーム から選べます。
  • 「応援履歴」から、取引ID・受取者着金額つきの領収書を表示できます。
ご注意：販売者は NTBase（運営会社）です。所定の手数料を差し引いた金額が選手・団体に分配されます。決済完了後のキャンセル・返金はできません。

VIEWER GUIDE 07

よくある質問

ログインできません
登録時の認証メールのリンクをクリックしたかご確認ください。メール認証が未完了の間はログインできません。
月額プランはありますか？
ありません。料金は大会ごとのPPV購入と、任意の投げ銭のみです。
動画を1本だけ購入できますか？
購入は大会単位です。購入するとその大会の全試合が視聴できます。
投げ銭を取り消したい
決済完了後のキャンセル・返金はできません。金額をよくご確認のうえご利用ください。
海外のクレジットカードは使えますか？
日本国外発行のカードはご利用いただけない場合があります。
登録したのに認証メールが届きません
まず迷惑メールフォルダをご確認ください。見つからない場合は、登録時のメールアドレスが間違っている可能性があります。正しいアドレスで再度登録をお試しください。
使える支払い方法は何ですか？
クレジットカードのみです。コンビニ払い・銀行振込には対応していません。

ATHLETE GUIDE 01

アカウントの始めかた

クラブからの招待で参加する（基本の流れ）

  1. 所属クラブから届く招待メールのリンクを開きます。招待リンクの有効期限は7日間です。
  2. 招待内容（所属申請 または 移籍オファー）を確認し、「承認する」または「拒否する」を選びます。
  3. 移籍オファーは承認から14日後に発効します。

自分で登録する

登録画面から名前・メールアドレス・パスワードで登録できます。登録後に届く認証メールのリンクをクリックするとログインできるようになります。

プロフィールを整える

ATHLETE GUIDE 05

応援（投げ銭）を受け取る

ダッシュボードの項目内容
累計応援額これまでに受け取った応援の合計
出金可能残高出金できる金額

選手直接とクラブ受取：応援には2つの受取区分があります。出金可能残高に加算されるのは「選手直接」分のみで、「クラブ受取」分は所属クラブに分配されます。1件ずつの内訳は「応援明細」で確認できます。

ATHLETE GUIDE 06

出金する

  1. 初回のみ「出金管理」から Stripe（決済代行）の口座登録を行います。Stripe アカウントを作成し、振込先の銀行口座を登録して連携完了。口座情報は Stripe が保持し、NTBase は保持しません。
  2. 毎月15日に自動出金されます。手続きは不要です。
  3. すぐに受け取りたい場合は「出金を申請する」から即時出金を申請できます。即時出金の場合のみ振込手数料がかかります。

出金状況は「出金申請済み / 処理中 / 送金手続完了」で確認できます。

ATHLETE GUIDE 07

よくある質問

招待メールのリンクが開けません
招待リンクの有効期限は7日間です。期限切れの場合はクラブの担当者に再送を依頼してください。
移籍を承認したのに反映されません
移籍は承認から14日後に発効します。
応援額と出金可能残高が一致しません
「クラブ受取」分はクラブに分配されるため、出金可能残高には「選手直接」分のみが加算されます。
自分の動画をアップロードしたい
動画の管理はクラブ（団体）アカウントで行います。所属クラブにご相談ください。

CLUB GUIDE 01

団体登録・ログイン

  1. 登録画面で、団体名・メールアドレス（ログイン用）・電話番号（任意）・管理者の姓名・パスワード（大文字・小文字・数字を含む8文字以上）・競技（テニス ピックルボール 両方）を入力し、利用規約に同意します。
  2. 届いた認証メールのリンクをクリックすると、ログインできるようになります（認証メールはログイン画面から再送できます）。
  3. ログイン後のダッシュボードで、団体情報・所属選手数・出金用口座（Stripe）の連携状況を確認できます。

メニューは ダッシュボード メンバー 大会管理 動画管理 出金管理 団体設定 です。管理画面は日本語のみの対応です。

CLUB GUIDE 02

選手（メンバー）を管理する

選手を個別に作成する

「選手を作成する」から、ニックネーム・生年月日・性別・主な戦績・活動期間・プロフィール画像・SNSリンク（X / Instagram / YouTube）を登録します。

メールで招待する

選手のメールアドレスに招待を送信できます。ステータスは「招待済み / 参加済み」で管理され、「招待再送」も可能です。招待リンクの有効期限は7日間です。登録済みの選手は「選手検索」から探して所属申請・移籍オファーを送れます（移籍は選手の承認から14日後に発効）。

CSVで一括登録する

  • ファイル制限：10MB以下・ファイル名50文字以内・拡張子 .csv
  • 形式：ヘッダー行必須、メールアドレス形式、性別は male / female / other、日付は YYYY-MM-DD

「所属選手別集計」では、選手ごとの応援総額・選手直接分・クラブ受取分・応援件数を確認できます。

CLUB GUIDE 03

大会を作成・管理する

「大会管理」→「大会作成」から、大会名・説明・開催期間・開催地・レベル・ランキング対象・PPV価格・バナー画像（横長 / モバイル用）・大会ロゴ・スポンサーロゴを設定します。

  • PPV価格を 0円 に設定すると無料公開になります。
  • 大会ごとに売上の受取先を クラブ受取 / 選手直接 から設定します。投げ銭・売上の分配先がこの設定で変わります。
  • PPV価格を設定した大会は、視聴者が大会単位で購入すると全試合を視聴できるようになります。

CLUB GUIDE 04

動画をアップロード・管理する

「動画管理」から、タイトル・説明・サムネイル（横 / 縦型）・プレビュー動画・本編動画・試合形式（シングルス / ダブルス など）・ジャンル・紐づける大会・出演選手・公開設定（公開 / 非公開 / 限定公開）を登録します。

  • サムネイル等の画像は2MB以下。動画は配信基盤（Mux）にアップロードされ、処理に時間がかかる場合があります。
  • プレビュー動画を設定すると、未購入の視聴者も一部を無料で観られるため、PPV購入の導線になります。
  • 出演選手を設定すると、選手アプリの動画一覧や選手の公開プロフィールに表示されます。

CLUB GUIDE 05

売上・出金を管理する

項目内容
PPV売上大会PPVの売上合計
投げ銭受取クラブ受取分の投げ銭合計
手数料合計プラットフォーム手数料（PPV 30% / 投げ銭 15%）
着金額手数料差引後の受取額
  1. 初回のみ、Stripe（決済代行）で出金用口座を連携します。口座情報は Stripe が保持します。
  2. 毎月15日に自動出金されます。すぐに受け取りたい場合は手動で出金申請できます。
  3. 取引明細はCSVでエクスポートできます。出金ステータスは「未申請 / 精算中 / 申請済み / 送金完了」です。

CLUB GUIDE 06

団体設定

「団体設定」から、団体名・紹介文・電話番号・管理者の姓名・メールアドレス・Instagramリンク・クラブ写真を変更できます。

CLUB GUIDE 07

よくある質問

選手に招待メールが届いていないようです
「メンバー」ページから「招待再送」ができます。招待リンクの有効期限は7日間です。
手数料はいくらですか？
PPV売上の30%、投げ銭の15%がプラットフォーム手数料です。差引後の着金額は「出金管理」で確認できます。
大会を無料で公開できますか？
できます。PPV価格を0円に設定してください。
動画がアップロードできません
サムネイル画像は2MB以下にしてください。動画本体の処理には時間がかかる場合があります。
